# Bilan global

## Ce que j'ai appris
- À découvrir et comprendre un projet existant grâce à Copilot.
- À développer une fonctionnalité en respectant les règles métier.
- À vérifier le fonctionnement du code avec des tests manuels et automatisés.
- À utiliser Vitest et Playwright pour tester une application.
- À vérifier qu'un test contrôle réellement le comportement attendu, et pas seulement qu'il passe.

## Ce que j'ai moins bien maîtrisé
- L'utilisation de MCP, qui n'a pas fonctionné dans notre environnement.

## Ce que j'aurais aimé apprendre davantage
- À utiliser Playwright MCP avec un agent IA.
- À mieux comprendre l'organisation générale du backend et du frontend.
- À créer des tests end-to-end plus complexes.

## Conclusion
Ce projet m'a permis de mieux comprendre le développement d'une application existante et l'utilisation de l'intelligence artificielle. J'ai surtout appris qu'il est important de toujours vérifier le code et les tests proposés par l'IA, plutôt que de leur faire entièrement confiance.
